If you have downloaded the entire project folder, the results have already been prepared.
To access the results dashboard, simply run *results.py* and open the server

If you do not have the results or wish to refresh the existing ones, run these files in order.
(1) run *component1.py* It will take a considerable runtime. This is normal.
(2) run *TrendAnalysis.py* It will take a considerable runtime. This is normal.
(3) run *trendrecs.py* Again, long runtime is normal.

The results are now updated. Run *results.py* and open the server.
